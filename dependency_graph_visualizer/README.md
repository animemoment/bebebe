# Dependency Graph Visualizer 2.0 — Code Intelligence & Architecture Suite

Профессиональный локальный аналитический комплекс для исследования графа зависимостей, чистоты архитектуры и рефакторинга проектов **Godot 4, C#, GDScript и сцен (.tscn)**.

---

## Быстрый запуск

### Windows (Без установки Python и зависимостей):
1. Запустите исполняемый файл **`DependencyGraphVisualizer.exe`**.
2. Браузер откроется автоматически: `http://127.0.0.1:8765`.
3. Нажмите кнопку **«📁 Обзор...»**, выберите папку любого Godot/C# проекта и нажмите **«⚡ Анализировать»** (или нажмите **«🎲 Демо»** для мгновенного ознакомления).

### Linux / macOS (или через исходники Python):
```bash
python3 app.py
```

### Автономный режим для ИИ-агентов (Claude, Cursor, Antigravity):
Инструмент поддерживает работу через консоль (CLI) без GUI:
```bash
# Документация для ИИ: см. AI_README.md
DependencyGraphVisualizer.exe --cli --project . --all-deps
DependencyGraphVisualizer.exe --cli --project . --skeletons
DependencyGraphVisualizer.exe --cli --project . --method "take_damage"
DependencyGraphVisualizer.exe --cli --project . --query --fields="name,mutations,hz" --budget=500
DependencyGraphVisualizer.exe --cli --project . --signals
DependencyGraphVisualizer.exe --cli --project . --scenes
DependencyGraphVisualizer.exe --cli --project . --orphans
DependencyGraphVisualizer.exe --cli --project . --hotpaths
DependencyGraphVisualizer.exe --cli --project . --chronology
```
Подробное руководство для нейросетей доступно в файле [AI_README.md](file:///D:/dependency_graph_visualizer/AI_README.md).

## 50+ Новых Возможностей и Улучшений (v2.0)

### 🔥 Новые супер-фичи экономии и оптимизации
- **🎯 AI Query Builder — Конструктор точечных выборок (экономия до 98% токенов)**: возможность для ИИ-агентов запрашивать *только* нужные поля (мутации, такты, вызовы, потоки данных), не захламляя контекст лишним кодом, с жестким контролем лимита бюджета токенов.
- **🔍 360° Рентген каждой функции (Function Deep-Dive)**: детальный паспорт любого метода проекта — сигнатура, цель на русском языке, список кто вызывает (Callers) и кого вызывает (Callees), мутации состояния, испускаемые сигналы, замеры частоты вызовов в 1 сек (Hz), такты CPU (~3.5 GHz) и цепочка Waterfall.
- **⏱️ Окно частоты вызовов в 1 сек (Hz) и тактов CPU**: замер частоты (0.05, 0.5, 1, 10, 60 Hz), процессорных тактов (~3.5 GHz базовой частоты), времени в мс и GC аллокаций.
- **🌊 Порядок выполнения и передача данных (Waterfall Flow)**: пошаговая хронология Шаг 1 → Шаг 2 → Шаг 3 с передаваемыми аргументами, мутациями переменных состояния и тактами каждого шага.
- **🎮 In-Game Telemetry vs Локальная симуляция**: сравнение и готовые скрипты `LiveProfiler.gd` / `LiveProfiler.cs` для снятия реальных замеров под физической нагрузкой.
- **💀 Скелеты публичных API (AST Skeletons, -90% токенов)**: вырезает тела методов, оставляя только типы, сигнатуры и сигналы. Экономит до 90% бюджета на контексте LLM!
- **📡 Глобальный реестр сигналов Godot и событий C#**: полная карта того, кто объявил сигнал, кто его шлет (`emit`) и кто слушает (`connect`).
- **🌲 Иерархия нод сцен (.tscn DOM Inspector)**: визуализация дерева сцен, путей `$NodePath` и уникальных нод `%UniqueNode`.
- **🏝 Ревизия мертвого кода (Truly Dead vs Scene Entry Points)**: умное разделение забытого мусора от скриптов, которые запускаются движком Godot из сцен.
- **⚡ Детектор горячих путей (60-FPS Hot-Paths)**: обнаружение методов `_process`, `_physics_process` и `Update` с рекомендациями против микрофризов и аллокаций памяти.
- **📖 Простые и понятные объяснения**: прямо в интерфейсе и инспекторе русским понятным языком объяснено значение каждого показателя (Нестабильность I, Blast Radius, Fan-in/out).

### 1. Архитектурный движок и метрики (Backend & Analytics)
1. **Парсинг сцен Godot (`.tscn`)**: автоматическое извлечение `ext_resource` (прикрепленные C#/GDScript скрипты и инстанцированные под-сцены).
2. **Анализ `project.godot` Autoload Singletons**: автоматическое определение глобальных синглтонов проекта с присвоением приоритетного статуса.
3. **Метрика нестабильности Роберта Мартина ($I$)**: вычисление $I = \frac{C_e}{C_a + C_e}$ для каждого файла ($I=0$ — фундамент/ядро, $I=1$ — координатор).
4. **Анализ радиуса поражения (Blast Radius)**: BFS-расчет всех файлов, которые прямо или транзитивно сломаются при изменении выбранного узла.
5. **Distance from Main Sequence ($D$)**: расчет сбалансированности классов и выявление компонентов в «Зоне боли» (Zone of Pain).
6. **Детектор God-Objects (Хабов)**: выявление классов с высокой связностью ($Degree \ge 12$) и большим объемом кода.
7. **Детектор мертвого/изолированного кода (Orphans)**: нахождение файлов без входящих и исходящих связей.
8. **Элементарные циклы и поиск слабого звена**: расчет точных цепочек циклов ($A \to B \to A$) и рекомендация ребра для разрыва.
9. **Классификация архитектурных слоев**: автоматическое распределение на `Autoload`, `Presentation/UI`, `Domain/Gameplay`, `Infrastructure`, `Core/Utils`.
10. **Проверка инверсии слоев (Clean Architecture)**: детекция нарушений, когда базовые доменные слои напрямую импортируют UI.
11. **Индекс здоровья архитектуры (0–100%)**: интегральная оценка кодовой базы на основе штрафов за циклы, хабы и нарушения.
12. **Разрешение вызовов методов**: оптимизированное связывание без квадратичного спама.

### 2. Набор инструментов для ИИ (AI & LLM Assistance Suite)
13. **Главный план рефакторинга**: готовый исчерпывающий промпт для Claude 3.7 / GPT-4o / Gemini / Cursor с анализом метрик и узких мест.
14. **Промпт разрыва циклов (DIP)**: целевые инструкции для ИИ по созданию интерфейсов и шин событий (Event Aggregator).
15. **Индивидуальный ИИ-промпт файла**: генерация детального контекста в инспекторе для конкретного выделенного файла.
16. **Декомпозиция монолитов (God-Objects)**: промпт для разбиения хабов по Single Responsibility Principle (SRP).
17. **Генератор GitHub Mermaid `graph TD`**: экспорт структуры связей с группировкой по подпапкам в буфер обмена.
18. **Генератор PlantUML**: создание компонентных диаграмм для корпоративной документации.
19. **Компактный архитектурный дайджест (<2,000 токенов)**: сверхплотная таблица интерфейсов для экономии контекстного окна LLM.
20. **Оценка расхода токенов**: подсчет примерного объема токенов перед отправкой в ИИ.

### 3. Структурные раскладки и физика (Layouts & Physics)
21. **Кластеры по папкам / модулям (`modules`)**: визуальные модульные боксы с полупрозрачными границами и названиями папок.
22. **Концентрические орбиты (`radial`)**: размещение ключевых хабов в центре с распределением периферии по внешним кольцам.
23. **Архитектурные слои DAG (`hierarchy`)**: поток от точек входа и Autoload слева к базовым утилитам справа.
24. **Сетка каталога (`grid`)**: упорядоченная алфавитная матрица.
25. **Органическая физика (`force`)**: дистанционно-ограниченная симуляция без зависаний.
26. **Плавный слайдер дистанции**: масштабирование расстояния между узлами от 100px до 420px.
27. **Жесткий анти-коллизионный буфер**: физический барьер, исключающий наложение узлов друг на друга.
28. **Стрелки направления (Arrowheads)**: четкие указатели потока зависимостей (кто от кого зависит).
29. **Плавные кривые связей (Bezier)**: квадратичные кривые для предотвращения перекрытия параллельных линий.

### 4. Цветовые схемы и тепловые карты (Themes & Heatmaps)
30. **4 цветовые темы оформления**:
    - **Dark Slate** (Сбалансированная темная тема)
    - **Midnight OLED** (Глубокий черный фон `#000` для максимальной контрастности)
    - **Cyberpunk Neon** (Неоновый синтвейв: циан, маджента, янтарь)

31. **Heatmap по нестабильности ($I$)**: градиент от зеленого (стабильные ядра) к красному (хрупкие координаторы).
32. **Heatmap по радиусу поражения (Blast Radius)**: подсветка степени риска изменений.
33. **Heatmap по объему кода (LoC)**: выявление самых раздутых файлов.
34. **Heatmap по числу связей**: мгновенная подсветка хабов и God-объектов яркой маджентой.
35. **Heatmap по слоям архитектуры**: разделение цветов по роли в проекте.
36. **Heatmap по подпапкам**: хэшированная уникальная палитра для каждого каталога.

### 5. Интерактивная навигация и UX
37. **Интерактивный радар-миникарта (Minimap)**: мини-обзор графа в правом углу с прямоугольником камеры и кликом для мгновенного перемещения.
38. **Слайдер глубины фокуса (Neighborhood 1-hop, 2-hop, 3-hop)**: фильтрация окружения вокруг выделенного узла.
39. **Поиск кратчайшего пути (Path Finder)**: выбор узлов A и B с подсветкой кратчайшей цепочки зависимостей золотой линией.
40. **Режим изоляции подсистемы**: скрытие всего лишнего шума вокруг выбранного компонента в один клик.
41. **Закрепление узлов (Pinning)**: возможность заморозить положение узла на полотне двойным кликом.
42. **Сравнение двух узлов (Side-by-Side Comparator)**: сопоставление метрик, общих потребителей и общих зависимостей в модальном окне.
43. **Заметки архитектора**: персональные заметки к файлам с автоматическим сохранением в `localStorage`.
44. **Закладки / Избранное**: добавление важных файлов в быстрый список (★) с сохранением в браузере.

### 6. Поиск, фильтры и экспорт
45. **Поддержка RegEx-поиска**: переключение на регулярные выражения кнопкой `.*`.
46. **Быстрые фильтры (Pills)**: кнопки мгновенного переключения «Все», «⚠️ Циклы», «👑 Hubs», «🏝 Изоляты».
47. **Выпадающий список фильтрации по папке**: просмотр только выбранного каталога.
48. **Векторный экспорт в SVG**: скачивание масштабируемой диаграммы для документации и печати.
49. **Снимок экрана в PNG**: скачивание текущего вида графа в высоком разрешении.
50. **Экспорт ребер в CSV**: выгрузка таблицы всех зависимостей (`source, target, type, confidence`).
51. **Открытие файла в VS Code**: прямая ссылка `vscode://file/...` прямо из инспектора.
52. **Копирование путей в буфер**: мгновенное копирование относительного или абсолютного пути.
53. **Горячие клавиши**:
    - `Space` — пауза/возобновление физики
    - `F` — вписать граф в экран (Fit)

    - `?` — окно справки и горячих клавиш

## Производительность (0% CPU в покое)
- Рендеринг Canvas 2D полностью переведен на пакетные вызовы (`batch drawing`) и событийную перерисовку по требованию (`requestAnimationFrame`).
- При бездействии пользователя нагрузка на процессор и видеокарту составляет **0.0%**.
- Отсечение невидимых элементов (`Viewport Bounds Culling`) обеспечивает плавные 60 FPS на графах из тысяч узлов.
