## 0. Константы
- Карта: 512x512, Tile 64px => 32768px. `MapRenderer.MapWidth/Height/TileSizePx`.
- Генерация (`MapGenerator`, сид-детерминирована, ~40-110мс на 512x512 в фоне): высоты fBm 4-5 октав scale 90-140 + island-falloff (море только у кромки) + порог воды 0.38-0.42; СТРОГО <=2 внутр. озёр (FloodFill, топ-2 >=300 кл., мелочь <150 засыпается, море по краю не в счёт); одна река downhill по heightMap (исток-верх, устье-край/озеро, ширина 1→2) + до 2 притоков (короче 40%, уже r=1); связность суши >=92% (брод-мосты до 4 кл., иначе retry); лес Poisson-disc по влаге+близости воды; старт-поляна R12 в центре без воды/деревьев; до 4 попыток (порог воды -0.015/попытка), иначе best-score. Лог: озёра/река/связность в `MapRenderer.GD.Print`.
- Время: сутки 12000с, час 500с (`WorldTime`). Авторитет `AgentSimulationThread.GameTimeSeconds` (volatile). Синк `Main._Process->TimeManager.SyncGameTime` троттлинг 10Гц (`_syncTimer>=0.1с`, п.6 — volatile-read 60/с убран, один `TimeOfDaySeconds` на тик).
- Скорости `GameSpeed 0/1/5/25/100`. Шаг `0.05с` (0.15 на 25x, 0.30 на 100x), maxSteps 8 (6 на 100x). Интервалы диспетчер 0.25с / рост 0.5с масштабируются `*max(1,speed/16)`. Снапшоты `MinSnapInterval=1/30с` (п.5: было 1/60 — генерация скана + MultiMesh upload каждый кадр убраны, dirty-check оставлен).
- Perf-режим (внесено, п.1-8): Ground `TryReserve/Take/Spawn/Release` без вложенного lock G->S (фильтр склада + `Withdraw` ВНЕ `Ground._lock`), тоталы `Interlocked/Volatile`, `HasAvailable*/HasFreeSpace` lock-free; `GenerateSnapshot` (Ground/Crop) копирует под коротким lock, строит ring вне секции; Stockpile `OnItemCountChanged` коалесцирован 200мс (`TickEventThrottle` из Phase2) + кэш `GetTotalItemCount` lock-free O(1) вместо O(N) скана; `CropGrowth.UpdateGrowth` без `new List(Keys)` (прямая итерация + lazy ready-буфер); `FlowField.Get/CalculateDetour` без `GameProfiler.Scope` (Contention ConcurrentDict убран); `MapRenderer` TileBatcher (`ConcurrentQueue<PendingCell>`, flush ≤2048/кадр, `QueueBlueprintRefresh` вместо `RefreshAll` на каждое событие); `ShadowCasterRenderer` дебаунс `PushBuffer` 150мс (`Add/Remove` только dirty); `FarmZoneRenderer` throttle `QueueRedraw` 100мс; `DesignationRenderer` 33мс→100мс; HUD статы 250мс→1с + время 500мс + `Text=` только при изменении.
- Фриз 16:45 thundering herd голода (исправлено): `TryReserveGroundItems` fast-fail по тоталам без lock + перегрузка с `maxChunkRadius` (еда: 3 чанка вместо 32, ~100x меньше работы под lock); `NeedsJobSystem.TryStartSeekingFood` резервирует точный вес еды (2 зерна, без Reserve/Release), неудача → `NeedsRetryTimer` 30-60с (отдельный от `JobSearchTimer`, тикает первым в Idle-бакете); спавн с джиттером Hunger/Sleep 0-20 (порог 70 пересекается растянуто, не в один тик 16:48).
- Phase3a/b разбор (P0 внесено): чанки Parallel 4096→1024 (10 чанков на 10k, было 3 — 13 ядер простаивали); `FlowField.GetDirection` ранний выход ≤5 тайлов без BFS 33x33 (~40-50% Phase3a); OnStart-резервы Delivery/Hauling/Planting лимит радиуса 4/4/3 чанка вместо 32 (остаточный конвой Ground._lock снят); `PushAgentAwayFrom` без `new[4]` (static readonly); `NeedsJobSystem` ThreadLocal RNG (Random.Shared contention + ctx.Random race устранены).
- Агенты: `Main.AgentCount=10000`. MoveSpeed 120, вода x0.45, ReachDist 48, Stuck>=3с => ReleaseForStuck.
- Потребности (SoA `AgentDataPool.Hunger/Sleep/Fatigue/EnvironmentSatisfaction/Mood/NeedsBehavior/NeedsRetryTimer` 0–100, `AgentNeedsConfig`, `NeedBehavior`): Hunger +0.5/игр.мин, Sleep +0.3/мин (всегда, сост. сна нет), Fatigue +0.2/мин в Working / -0.4/мин в Idle, Env заглушка 80 раз в 500с (1 игр.час, `_needsEnvTimer`), Mood=100-(0.35*Hunger+0.25*Sleep+0.2*Fatigue+0.2*(100-Env)). deltaTime шагов уже в игр.времени — домножения на speed не нужно. Пороги реакций: Hunger>70 еда, Sleep>80/Fatigue>80 отдых, Env<40 миграция; Fatigue>80 скорость x0.85.
- Длительности (игр.с): рубка 3000 (6ч), вскопка 125 (0.25ч), стройка 2000 (4ч), посадка 10, сбор 5, рост 60/фаза.
- Правило: все MultiMesh `CustomAabb (32768,32768,1000)` иначе culling.
- Чанки 32x32 по 16x16 (`ChunkShift=4`). Регионы pathfinder 16x16.
- Z: Items 5, Crop 6, FarmZone 8, Agent 10, Designation 15, Selection 100, Overlay 120.
- День/ночь: один `CanvasModulate` (`Main.DayNightModulate` + `src/ui/DayNightCycle.cs`), тинт=f(TimeOfDay), O(1) GPU, 0 draw-call. Ключи (ч): ночь<5, рассвет 6.5 (1,0.78,0.58), день 8-17 (1,1,1), закат 18.5 (1,0.55,0.35), ночь>=20 (0.23,0.27,0.46). Тик 10Гц + eps 0.002/канал. Реальных Light2D-теней нет (shadow-pass по 10k+TileMap 512 в gl_compatibility). HUD в CanvasLayer не тинтится; иконка ☀/☾ в WorldTimeLabel.
- Солнце/тени (`DayNightCycle.SampleSun->SunState{Dir,LengthPx,WidthScale,Alpha}`, `ShadowCasterRenderer` Z4, `AgentRenderer.AgentShadowInstance` свой MultiMesh): фейк-направленные растяжением от опоры, дуга слева направо (восход 6ч, полдень 13ч, закат 20ч; утро тень -X, вечер +X, полдень длина 0). Длина max 28px (1-elev), ширина 0.55, альфа max 0.32, ночью скрыты. Статика (деревья/стены/здания): 1 MultiMesh клина 32x64 (плотно у ствола, прозрачно к концу), якорь=низ тайла, матрица R(dir)*S(len,width), cap 65536, буфер только при смене солнца/рубке/стройке, +1 draw-call; масштабы статики 0.65 длина / 0.7 ширина / 0.45 альфа (иначе рощи сливаются в blobs). Агенты: силуэт фермера своим буфером count*8, якорь=ноги, заливка в том же _Process (+~1ms на 10k), +1 draw-call. Buffer Transform2D: x.x,x.y,pad,ox,y.x,y.y,pad,oy. Тик в `Main._Process` scope `Render: Shadows`. Кастеры: RebuildStatic в ApplyMap, Add/Remove при рубке/стройке/сносе.

## 3. SimThread (фон Task.Run)
- `Start`: сбор walkableTiles, AgentDataPool, SpatialGrid+Movement+ctx(Ground/TreeOnGrass/SolidWalls/Walkable/SpatialGrid/Movement/Random/TileSize), `JobRegistry.Register`(8 хендлеров), Pathfinder.Build, ring[16].
- Цикл: acc+=realDelta*speed; Step пока acc>=0.05 (max 5): Phase1_ParallelMove (Parallel чанки 4096: ExecuteParallel + Wander + Bookkeep CellStay/JobSearch i&3==bucket + UpdateWorkerChunk), Phase2_Dispatch (таймер Dispatch=>`JobDispatcher.DispatchPendingJobs`+batchScale; StockpileSweep; `CropGrowth.UpdateGrowth`+GenerateSnapshot; GroundItem.GenerateSnapshot), Phase3b_SequentialCommit (перестрой SpatialGrid + Commit), GameTimeSeconds+=dt, PushSnapshot (PositionQueue cap 2). Sleep(0) горячие / Sleep(1) холодные при speed>=25.
- Потребности: `_needsEnvTimer+=dt`, раз в 500с флаг `updateNeedsEnvThisStep` => `Phase3a_ParallelBookkeeping(dt,isLast,flag)` => `UpdateNeedsSingleAgent` первой строкой `BookkeepSingleAgent` (покрывает все состояния, Parallel чанки 4096): Hunger/Sleep линейно, Fatigue по `States` (Working+/Idle-), Env заглушка, Mood взвешенный. Без домножения на speed (dt уже игровой).
- Реакции (лёгкий NeedsJobSystem): Idle + тик `(i&3)==bucket` => `TryAssignNeedsBehavior` ДО `JobSearchTimer` (нужда приоритетнее работы): SeekingFood резерв Grain чанк-поиск `GroundItemManager` r40 + `MoveTowards` + `TakeItems` в `CommitEating`; Resting на месте; Migrating r24 с `IsCellOvercrowded` по `AgentSpatialGrid`; транспорт Evacuating (диспетчер игнорит), возврат в Idle через `IdleWorkers`. Усталые (`Fatigue>80`) идут x0.85 (`MoveToPoint`).

## 4. Jobs
